# Mainflix artwork

The sheep/filmstrip mark and cinematic sheep/creeper landscape were generated with the built-in image generation tool from the user's supplied brand references and approved interface preview on 2026-11-09.

- `mainflix-mark.webp`: compact transparent sheep and filmstrip brand icon; the PNG preserves the original generated source.
- `movie-night-hero.webp`: cinematic voxel sunset valley with sheep and creeper on the right, without baked-in interface elements or text.
- `diamond.png`: existing 16×16 pixel-art diamond from the design assets, by the LibreProg artists and developers; distributed under the included `LIBREPROG-LICENSE.txt` (BSD 3-Clause).

Prompt intent: premium cinematic Minecraft-inspired 3D voxel artwork; use the approved sheep/filmstrip logo as branding inspiration; keep the hero's left side clear for live HTML text. Responsive framing and all controls are implemented in CSS and React.

Mainflix is an unofficial fan project and is not affiliated with Mojang, Microsoft, Netflix or TMDB. Actual film artwork continues to come from the application's TMDB integration.
